# Reels Stüdyo

Ücretsiz Instagram Reels video hazırlama uygulaması. Telefon tarayıcısından çalışır; konuya göre kural tabanlı sahne taslağı, fotoğraf/müzik ekleme, 9:16 ön izleme ve video dışa aktarma sunar.

## GitHub Pages üzerinde yayın

Repository **Settings → Pages** bölümünde **Build and deployment** için **Deploy from a branch**, Branch olarak **main** ve klasör olarak **/(root)** seçilerek **Save** yapılır.

Yayın adresi: https://filorensuarez.github.io/reels-studyo/

Android Chrome ile bu adres açılır ve menüden **Uygulamayı yükle** veya **Ana ekrana ekle** seçilir.

Not: Metin oluşturma özelliği gerçek üretken yapay zekâ değil, kural tabanlıdır. MP4 dışa aktarımı cihaz/tarayıcı desteğine bağlıdır. Gerekli bazı MP4 dönüşümleri için harici FFmpeg dosyaları internetten indirilir. Kullanıcının eklediği fotoğraflar ve sesler uygulamanın kendi sunucusuna yüklenmez.
